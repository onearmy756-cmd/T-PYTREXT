🔑 Key Features

🔗 Blockchain

SHA-256 immutable ledger. Create, verify, audit blocks. Tamper detection built-in. Perfect for finance, voting, supply chain.

🔐 AES-256 Encryption

Military-grade encryption. Encrypted SQLite database. Memory zeroization. Secure key management.

🧠 AI/ML Engine

LangChain + Hermes Agent + PyTorch + Candle + Burn + RAG. Build intelligent apps with one line.

🌐 Real-Time

Elixir BEAM VM handles millions of concurrent connections. Perfect for chat, trading, live dashboards.

🤖 MCP Protocol

Model Context Protocol — Server + Client. Expose tools to AI models. Connect to external MCP servers.

👤 Human-in-the-Loop

Approval workflows for AI actions. Timeout management. Audit trail. Tauri notifications.

🔍 Web Search

SearXNG + DuckDuckGo integration. Multi-engine search with automatic fallback. RAG-ready.

🖥️ Desktop UI

Tauri v2 lightweight webview. No Chromium bloat. Cross-platform: Windows, macOS, Linux.
