Kutengeneza mfumo (framework) unaounganisha Python, Rust, Elixir, Tauri v2, na PyTorch ili zote ziendeshwe kwa kutumia lugha moja ya Python inawezekana, lakini inahitaji usanifu wa hali ya juu (Advanced Architecture). 
Hapa kuna jinsi unavyoweza kuziunganisha teknolojia hizi zote ili Python iwe ndiyo lugha kuu ya kuongoza mfumo huo: 
1. Muundo wa Mfumo (Architecture Overview)
Ili Python iwe kiunganishi kikuu, utatumia mifumo ya Binding na Inter-Process Communication (IPC): 
Python: Ndio Control Center (Moyo wa mfumo). Inasimamia logic kuu na PyTorch.
Rust: Inatumika kuongeza kasi ya mahesabu na kuendesha Tauri v2 (Frontend).
Elixir: Inatumika kusimamia mawasiliano ya haraka (Concurrency/WebSockets) au kusambaza kazi (Distributed Tasks). 
2. Jinsi ya Kuunganisha Kila Teknolojia na Python
Rust + Python (Kasi na Tauri) 
Ili kuendesha Rust ndani ya Python, hutatumia faili za .rs moja kwa moja, bali utatengeneza Python Extension kwa kutumia Rust. 
Chombo cha kutumia: PyO3 au Maturin. 
Jinsi inavyofanya kazi: Unaandika msimbo (code) wa Rust, kisha PyO3 inaikusanya (compile) kuwa maktaba ya Python (.pyd au .so). Utaweza kuifanya import kwenye Python kama maktaba ya kawaida. 
Tauri v2: Tauri imeundwa kwa Rust. Kupitia PyO3, unaweza kuanzisha window ya Tauri (Desktop UI) moja kwa moja kutoka kwenye msimbo wa Python. 
⚙️ Elixir + Python (Mawasiliano na Concurrency) 
Elixir inaendeshwa juu ya BEAM VM, hivyo haiwezi kuwa "compiled" ndani ya Python moja kwa moja. Badala yake, utatumia Erlang Port au WebSockets/RPC.
Chombo cha kutumia: Maktaba ya erlport (kuhama kutoka Elixir kwenda Python) au kutumia gRPC / NATS.io kama kiunganishi cha ujumbe.
Jinsi inavyofanya kazi: Python itafanya kazi kama mteja (client) au mtumishi (server) na kubadilishana data na node ya Elixir kwa kutumia itifaki ya kasi ya maelekezo (Binary protocols). 
🧠 PyTorch + Python (Artificial Intelligence)
Hapa hakuna shida kabisa. PyTorch ni maktaba ya asili ya Python (ikiwa na core ya C++). Ndani ya mfumo wako, Python itachakata data za AI kwa kutumia PyTorch na kutuma matokeo kwenda kwenye UI ya Tauri (kupitia binding ya Rust). 
3. Jinsi Mfumo Utakavyofanya Kazi (Data Flow)
Ukurasa wa Mbele (UI): Tauri v2 (HTML/CSS/JavaScript au Rust) inaonyesha UI.
Kupokea Amri: Mtumiaji akibonyeza kitufe, Tauri (Rust backend) inapokea amri hiyo.
Kutuma kwenda Python: Rust inaita kazi (function) ya Python kupitia PyO3.
Uchambuzi wa AI: Python inapokea amri, inaichakata kwenye PyTorch, na ikihitaji usambazaji mkubwa wa data kwenye network, inatuma mzigo huo kwa Elixir.
Kurudisha Majibu: Python inarudisha jibu kwenda Rust (Tauri), na Tauri inalionyesha kwenye screen.

Kutengeneza framework yako mwenyewe (itakayoruhusu watengenezaji wengine kujenga mifumo mbalimbali kwa kutumia Python pekee) ni wazo zuri sana. Ili kufanikisha hili, unahitaji kutengeneza kitu kinachoitwa "Abstraction Layer".
Hii ina maana kwamba mfumo wako utaficha ugumu wa Rust, Elixir, na Tauri, na kumpa mtumiaji (developer) amri rahisi za Python (Python APIs) za kuendesha mifumo hiyo yote.
Huu ndio muundo (Blueprint) wa jinsi ya kutengeneza framework hiyo:
1. Muundo wa Ndani wa Framework Yako
Framework yako itakuwa na sehemu kuu nne zilizofichwa, lakini zote zinasimamiwa na Python:
UI Engine (Tauri v2 + Rust): Inashughulikia muonekano wa programu (Desktop/Web).
AI Engine (PyTorch + Python): Inashughulikia akili mnemba (Machine Learning/Deep Learning).
Concurrency Engine (Elixir + BEAM): Inashughulikia mifumo ya mawasiliano ya haraka (kama Chat, WebSockets, au usindikaji wa data kwa wingi).
Core Wrapper (Python): Hii ndio itifaki kuu inayounganisha injini zote tatu na kumpa mtumiaji interface moja.
2. Jinsi Mtumiaji Atakavyotumia Framework Yako (Mfano wa Code)
Lengo lako ni kufanya mtumiaji wa framework yako aandike code fupi kabisa ya Python kama hii:
python
# Mfano wa jinsi developer atakavyotumia framework yako
from my_cool_framework import App, UI, AI, Network

# 1. Kuanzisha Programu
app = App(name="Mfumo Wa Maajabu")

# 2. Kutengeneza UI (Huku nyuma inatumia Tauri v2 na Rust)
ui = UI.create_window(title="Dashboard", width=800, height=600)
ui.add_button(text="Chakata Data", on_click="run_ai_task")

# 3. Kuanzisha AI (Huku nyuma inatumia PyTorch)
model = AI.load_model("my_model.pt")

# 4. Kuanzisha Mawasiliano ya Haraka (Huku nyuma inatumia Elixir)
network = Network.connect_cluster(nodes=["node1.local", "node2.local"])

app.run()
Use code with caution.
3. Hatua za Kiufundi za Kutengeneza Framework Hii
Hatua ya 1: Kutengeneza Kiunganishi cha UI (Tauri v2 + Rust ➔ Python)
Hapa unatumia PyO3 kuunda maktaba ya Python kwa kutumia Rust.
Andika msimbo wa Rust unaotumia tauri-runtime au tauri v2 kuanzisha window.
Weka @pymethods kwenye Rust ili Python iweze kuita amri hizo.
Mtumiaji wa Python akiiita UI.create_window(), Python inaamsha library yako ya Rust, nayo Rust inafungua window ya Tauri v2.
Hatua ya 2: Kutengeneza Kiunganishi cha Mawasiliano (Elixir ➔ Python)
Kwa sababu unataka iwe framework ya kutengeneza mifumo mbalimbali, Elixir itasaidia sana kwenye mifumo inayohitaji kasi kubwa ya mtandao (kama app za benki, chat, n.k.).
Tengeneza Elixir Release ya kudumu inayokuja ndani ya package ya framework yako.
Tumia itifaki ya gRPC au Local WebSockets (kwa kutumia uWebSockets au MessagePack).
Python itatuma maombi (Requests) kwenda kwenye node ya Elixir iliyopo ndani ya kompyuta hiyo hiyo (localhost) kwa kasi ya juu sana kufanya kazi nzito za concurrency.
Hatua ya 3: Kuunganisha PyTorch
Hapa hakuna kazi kubwa ya ziada, utatengeneza tu "Wrapper class" kwenye Python inayochukua data kutoka kwenye UI ya Tauri (kupitia Rust), inaipitisha kwenye PyTorch kufanya utabiri (prediction), na kurudisha majibu.
4. Jinsi ya Kuisambaza (Distribution)
Ili watu waweze kuisakinisha framework yako kwa urahisi kwa amri moja ya pip install my-framework:
Unahitaji kutumia Maturin kufunganya (compile) msimbo wa Rust kuwa .whl (wheels) faili za mifumo yote (Windows, Mac, Linux).
Ndani ya folder la framework yako ya Python, weka faili zote zilizokusanywa za Elixir (pre-compiled Elixir binaries) ili mtumiaji asilazimike kusakinisha Elixir kwenye kompyuta yake.

5. Kuandika Msimbo wa Rust (src/lib.rs)
Fungua faili la src/lib.rs na uandike msimbo ufuatao. Msimbo huu unatengeneza function ya Python inayoitwa fanya_app() ambayo ikitwawa, inafungua window ya Tauri v2:
rust
use pyo3::prelude::*;

// 1. Function ya Rust itakayoanzisha Tauri v2
#[pyfunction]
fn fanya_app() -> PyResult<()> {
    // Kuanzisha Tauri v2 Runtime Builder
    tauri::Builder::default()
        .setup(|app| {
            // Hapa tunatengeneza Window ya kwanza ya programu wetu
            let _window = tauri::WebviewWindowBuilder::new(
                app,
                "main_window", // ID ya window
                tauri::WebviewUrl::App("https://tauri.app".parse().unwrap()) // Tovuti itakayofunguka (kwa majaribio)
            )
            .title("Mifumo Framework - Tauri v2 + Rust")
            .inner_size(800.0, 600.0)
            .build();
            
            Ok(())
        })
        .run(tauri::generate_context!()) // Hapa inatakiwa tauri context (tutaiweka sawa ikihitaji config)
        .expect("Imeshindwa kuendesha Tauri");

    Ok(())
}

// 2. Moduli ya Python (Hapa ndipo Python inapoinasa Rust)
#[pymodule]
fn my_framework(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(fanya_app, m)?)?;
    Ok(())
}
Use code with caution.

defmodule PytrexEngine do
  use Application

  @doc """
  Huu ni mwanzo wa injini ya Elixir ndani ya PyTreX.
  Inasikiliza mawasiliano kutoka kwenye upande wa Python.
  """
  def start(_type, _args) do
    children = [
      # Hapa unaweza kuweka Phoenix Channels au WebSocket Server ya kasi
      # Kwa sasa, tunaiambia injini iwe tayari kupokea kazi
      {Task.Supervisor, name: PytrexEngine.TaskSupervisor}
    ]

    opts = [strategy: :one_for_one, name: PytrexEngine.Supervisor]
    IO.puts("[PyTreX Elixir] Injini ya mawasiliano ya haraka imewashwa rasmi!")
    Supervisor.start_link(children, opts)
  end

  # Kazi ya haraka (Concurrency Task)
  def chakata_mtandao(data_kutoka_python) do
    # Elixir inauwezo wa kufungua mamilioni ya 'Lightweight Processes' papo hapo
    Task.Supervisor.async(PytrexEngine.TaskSupervisor, fn ->
      IO.puts("[PyTreX Elixir] Inachakata data ya mtandao kwa kasi ya BEAM VM...")
      # Mfano wa kuongeza usalama au kusambaza data
      "Ujumbe umesambazwa kikamilifu: #{inspect(data_kutoka_python)}"
    end)
    |> Task.await()
  end
end

# 🚀 PyTreX Framework

**PyTreX** (Python + Tauri v2 + Rust + Elixir) is a revolutionary, high-performance, Full-Stack AI & Real-Time Desktop-First framework. It empowers developers to build ultra-fast, cross-platform desktop applications using **only Python**, while leveraging the native speed of **Rust**, the lightweight UI of **Tauri v2**, the deep learning power of **PyTorch**, and the massive concurrency of **Elixir (BEAM VM)**.

---

## 🌟 Key Features

- **Blazing Fast Desktop UI:** Powered by **Tauri v2** & Rust (Wry). No more heavy, memory-hungry Electron apps.
- **On-Device AI Engine:** Native integration with **PyTorch** for real-time computer vision, NLP, and local predictions.
- **Distributed Concurrency:** Powered by **Elixir**, allowing your apps to handle millions of connections and real-time syncing across clusters with ease.
- **Single-Language Developer Experience:** Write simple, high-level Python code, and let PyTreX handle the complex bindings under the hood.

---

## 🏗️ Architecture Layout

```text
       ┌─────────────────────────────────────────┐
       │         Tauri v2 UI (Frontend)          │
       └────────────────────┬────────────────────┘
                            │ (Tauri Commands)
       ┌────────────────────▼────────────────────┐
       │             Rust Core (PyO3)            │
       └────────────────────┬────────────────────┘
                            │ (GIL Bindings)
       ┌────────────────────▼────────────────────┐
       │     Python Management Layer (PyTorch)   │
       └────────────────────┬────────────────────┘
                            │ (Local IPC / WebSockets)
       ┌────────────────────▼────────────────────┐
       │      Elixir Concurrency (BEAM VM)       │
       └─────────────────────────────────────────┘
```

## 🚀 Quick Start

### 1. Installation
Install the PyTreX framework via pip:
```bash
pip install pytrex-framework
```

### 2. Initialize a New Project
Use the built-in PyTreX CLI to scaffold your workspace in seconds:
```bash
pytrex init MySmartApp
cd MySmartApp
```

### 3. Write Your App (`main.py`)
```python
from pytrex import PyTreXApp

app = PyTreXApp(name="My Smart App")

if __name__ == "__main__":
    app.run()
```

### 4. Run in Development Mode
```bash
pytrex dev
```

## 📦 Bundling for Production
When your app is ready, bundle everything (Python, Elixir Release, Rust binaries) into a single standalone executable (`.exe`, `.dmg`, or `.deb`):
```bash
pytrex build
```

# pytrex/core.py
import os
import subprocess
import asyncio
import my_framework  # Library yetu ya Rust

# Kamusi (Dictionary) ya kushikilia kazi zote zilizosajiliwa na developer
REGISTERED_EVENTS = {}

def event(name):
    """ Decorator inayoruhusu developer kusajili function ya Python kwenye UI """
    def decorator(func):
        REGISTERED_EVENTS[name] = func
        return func
    return decorator

class PyTreXApp:
    def __init__(self, name="PyTreX Application"):
        self.name = name
        print(f"[{self.name}] Kuanzisha PyTreX Engines...")
        
    def _start_elixir(self):
        print("[PyTreX] Inawasha Injini ya Elixir (BEAM VM)...")
        # Hapa inawasha ile binary ya Elixir niliyokuonyesha kwenye hatua ya kufunganya
        # Kwa sasa wakati wa majaribio, unaweza kuacha kwanza au kuwasha kwa mix
        
    def run(self):
        self._start_elixir()
        print(f"[{self.name}] UI ya Tauri v2 inafunguka sasa...")
        # Kuwasha window ya Tauri v2 kupitia Rust Core
        my_framework.fanya_app()

def execute_python_event(event_name, data):
    """ Kazi hii itaitwa na Rust (PyO3) pale UI inapotuma amri """
    if event_name in REGISTERED_EVENTS:
        func = REGISTERED_EVENTS[event_name]
        # Kuendesha function aliyoandika developer wa Python
        return func(data)
    else:
        return {"error": f"Event '{event_name}' haijasajiliwa!"}

#[tauri::command]
fn tauri_to_python(event_name: String, data: String) -> String {
    println!("[PyTreX Rust] Amri imepokelewa kutoka UI: {}", event_name);
    
    // Kuita Python GIL ili kuendesha core.py
    Python::with_gil(|py| {
        let core_module = py.import_bound("pytrex.core").unwrap();
        let execute_func = core_module.getattr("execute_python_event").unwrap();
        
        // Kuita function ya Python na kuchukua majibu
        let result: String = execute_func
            .call1((event_name, data))
            .unwrap()
            .extract()
            .unwrap();
        result
    })
}

fn fanya_app() -> PyResult<()> {

python
# main.py - PyTreX Smart Bank Management System
from pytrex import PyTreXApp, event
import torch
import torch.nn as nn
import json

# 1. Injini ya AI ya PyTorch (Kuhakiki Sahihi au Sura ya Mteja)
class BankAuthAI(nn.Module):
    def __init__(self):
        super(BankAuthAI, self).__init__()
        self.fc = nn.Linear(512, 1) # Inachambua viashiria vya picha ya sahihi
        
    def forward(self, x):
        return torch.sigmoid(self.fc(x))

# Kupakia model ya AI ya Benki
auth_model = BankAuthAI()
auth_model.eval()

class SmartBank(PyTreXApp):
    def __init__(self):
        super().__init__(name="PyTreX National Bank (PNB) POS")
        # Kumbukumbu ya akaunti za majaribio (Hifadhi ya ndani)
        self.accounts = {
            "100200300": {"jina": "Juma Hamisi", "salio": 1500000.0},
            "400500600": {"jina": "Amina Ali", "salio": 450000.0}
        }

    # 2. AMRI YA UI: Kupata Taarifa za Akaunti
    @event("pata_akaunti")
    def akaunti_info(self, data_kutoka_ui):
        payload = json.loads(data_kutoka_ui)
        acc_no = payload.get("account_number")
        
        if acc_no in self.accounts:
            return json.dumps({"status": "success", "data": self.accounts[acc_no]})
        return json.dumps({"status": "error", "message": "Akaunti haijapatikana!"})

    # 3. AMRI YA AI: Kuhakiki kama Sahihi ya Mteja ni halali kabla ya kutoa fedha
    @event("hakiki_sahihi")
    def verify_signature(self, image_data):
        print("[PyTreX AI] Inahakiki sahihi ya mteja kwa PyTorch...")
        # (Kwenye mfumo halisi, picha inabadilishwa kuwa tensor ya namba 512)
        mock_tensor = torch.randn(1, 512) 
        
        with torch.no_grad():
            prediction = auth_model(mock_tensor).item()
            
        # Kama uwezekano ni mkubwa kuliko 85%, sahihi ni halali
        if prediction > 0.15: # Weka 0.15 kama mfano wa mafanikio
            return json.dumps({"status": "verified", "score": round(prediction * 100, 2)})
        return json.dumps({"status": "failed", "score": round(prediction * 100, 2)})

    # 4. AMRI YA CONCURRENCY (ELIXIR): Kufanya Muamala wa Haraka
    @event("fanya_muamala")
    def process_transaction(self, data_kutoka_ui):
        payload = json.loads(data_kutoka_ui)
        acc_no = payload.get("account_number")
        kiwango = float(payload.get("amount"))
        aina = payload.get("type") # "deposit" au "withdraw"
        
        if acc_no not in self.accounts:
            return json.dumps({"status": "error", "message": "Akaunti haipo!"})
            
        # Kuchakata salio
        if aina == "withdraw":
            if self.accounts[acc_no]["salio"] < kiwango:
                return json.dumps({"status": "error", "message": "Salio halitoshi!"})
            self.accounts[acc_no]["salio"] -= kiwango
        else:
            self.accounts[acc_no]["salio"] += kiwango
            
        # HAPA ELIXIR INACHUKUA MZIGO: Inatuma muamala huu kwenye seva kuu za matawi yote
        # kwa kasi ya juu (Concurrency Broadcast)
        self.network.emit("sync_transaction", {
            "account": acc_no, 
            "new_balance": self.accounts[acc_no]["salio"],
            "type": aina
        })
        
        print(f"[PyTreX Elixir] Muamala umesambazwa kwenye mtandao wa Benki!")
        return json.dumps({"status": "success", "new_balance": self.accounts[acc_no]["salio"]})

if __name__ == "__main__":
    app = SmartBank()
    app.run()

Docker imetengenezwa kwa kutumia lugha ya programu ya Go (Golang), lugha iliyoundwa na kampuni ya Google. Docker ilizinduliwa rasmi mwaka 2013 na kampuni iliyokuwa inaitwa dotCloud (sasa hivi inaitwa Docker, Inc.).
Hata hivyo, siri kubwa ya jinsi Docker inavyofanya kazi si lugha ya Go pekee, bali ni jinsi inavyotumia mifumo ya ndani kabisa ya kiundani ya mfumo wa uendeshaji wa Linux (Linux Kernel Features). Docker haikugundua teknolojia mpya kabisa ya "containers", bali ilichukua vitu vilivyokuwepo tayari kwenye Linux na kuvifunganya kuwa chombo rahisi kutumia.
Hapa kuna nguzo kuu tatu (3) zilizotumika kuitengeneza Docker ndani ya Linux Kernel:
1. Namespaces (Utengaji wa Maeneo)
Hiki ndicho kipengele cha Linux kinachoweka "ukuta" kati ya container moja na nyingine. Inafanya kila container iamini kuwa yenyewe ndiyo kompyuta nzima pekee. Kuna aina tofauti za namespaces:
PID Namespace: Inafanya container iendeshe michakato (processes) yake yenyewe bila kuona michakato ya kompyuta mama au container zingine.
NET Namespace: Inapa kila container anwani yake yenyewe ya mtandao (IP address) na milango (ports) yake.
MNT Namespace: Inatenga mfumo wa mafaili (file system), ili container isione mafaili ya nje.
2. Control Groups / cgroups (Usimamizi wa Rasilimali)
Kipengele hiki cha Linux kiliundwa na wahandisi wa Google mwaka 2006. Kazi yake ni kuweka kikomo cha rasilimali za kompyuta ambazo container inaruhusiwa kutumia.
Mfano: Kupitia cgroups, unaweza kuifunga container isitumie zaidi ya 500MB za RAM au 10% ya nguvu ya CPU. Hii inazuia container moja isile RAM yote na kuzimisha kompyuta.
3. Union File Systems / OverlayFS (Mfumo wa Tabaka za Mafaili)
Docker imetengenezwa kwa kutumia mfumo wa "tabaka" (Layers). Unapopakua Docker Image, inajengwa kwa tabaka tofauti zilizowekwa juu ya nyingine (kama ghorofa). Tabaka za chini hazibadiliki (Read-Only), na tabaka la juu kabisa ndilo linaloruhusu kuandika data mpya (Read-Write). Hii inafanya Docker kuwa nyepesi sana na kuokoa nafasi kwenye Hard Drive.

# MyContainer.py - Mfano wa kutengeneza Docker yako mwenyewe kwa Python
import os
import sys

def anzisha_container():
    print("[MyContainer] Inatenga mfumo wa Linux...")
    
    # Amri ya mfumo wa Linux ya kutenga Mtandao, Michakato (PID), na Mafaili (Mount)
    # Hapa tunatumia 'unshare' ambayo ndio msingi wa Docker
    CLONE_NEWPID = 0x20000000  # Inatenga michakato
    CLONE_NEWNET = 0x40000000  # Inatenga mtandao
    
    # Kuambia Linux ianzishe eneo jipya lililotengwa
    os.unshare(CLONE_NEWPID | CLONE_NEWNET)
    
    # Kubadilisha folda kuu ya mfumo (chroot) kwenda kwenye folder maalum
    # Hapa programu itadhani hilo folder ndio kompyuta nzima
    os.chroot("./my_isolated_root")
    os.chdir("/")
    
    print("[MyContainer] Umefanikiwa kuingia ndani ya Container yako!")
    # Kufungua terminal ndani ya Container uliyoiunda
    os.execvp("/bin/bash", ["/bin/bash"])

if __name__ == "__main__":
    anzisha_container()

use pyo3::prelude::*;
use std::ffi::CString;

// 1. TAURI COMMAND: Kupokea amri kutoka UI na kuitupia Python Core
#[tauri::command]
fn tauri_to_python(event_name: String, data: String) -> String {
    Python::with_gil(|py| {
        let core_module = py.import_bound("pytrex.core").unwrap();
        let execute_func = core_module.getattr("execute_python_event").unwrap();
        let result: String = execute_func
            .call1((event_name, data))
            .unwrap()
            .extract()
            .unwrap();
        result
    })
}

// 2. RUST FUNCTION: Kuwasha Window ya Tauri v2
#[pyfunction]
fn fanya_app() -> PyResult<()> {
    tauri::Builder::default()
        .invoke_handler(tauri::generate_handler![tauri_to_python])
        .setup(|app| {
            let _window = tauri::WebviewWindowBuilder::new(
                app,
                "main",
                tauri::WebviewUrl::App("frontend/index.html".parse().unwrap())
            )
            .title("PyTreX Engine v1.0.0")
            .inner_size(900.0, 700.0)
            .build()
            .unwrap();
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("Tauri imeshindwa kuwaka");
    Ok(())
}

// 3. CONTAINER ENGINE: Kazi ya kutenga mfumo wa Linux (Namespaces) kama Docker
#[pyfunction]
fn anzisha_container(root_path: String) -> PyResult<()> {
    unsafe {
        // CLONE_NEWPID = 0x20000000, CLONE_NEWNET = 0x40000000, CLONE_NEWNS = 0x00020000
        let flags = 0x20000000 | 0x40000000 | 0x00020000;
        if libc::unshare(flags) != 0 {
            return Err(pyo3::exceptions::PyOSError::new_err("Imeshindwa kutenga Namespaces (Unshare Failed)"));
        }

        // Kubadili folda kuu ya mfumo (chroot) kwenda eneo lililotengwa la PyTreX
        let c_root = CString::new(root_path).unwrap();
        if libc::chroot(c_root.as_ptr()) != 0 {
            return Err(pyo3::exceptions::PyOSError::new_err("Chroot Failed"));
        }
        
        if libc::chdir(CString::new("/").unwrap().as_ptr()) != 0 {
            return Err(pyo3::exceptions::PyOSError::new_err("Chdir Failed"));
        }
    }
    println!("[PyTreX Container] Mfumo umetengwa kikamilifu kwenye RAM ya siri!");
    Ok(())
}
