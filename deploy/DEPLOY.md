# testapp — Production Deployment Guide

## Quick Deploy

### Docker (recommended)
```bash
cd deploy
docker-compose up -d
```

### Docker (manual)
```bash
docker build -t testapp -f deploy/Dockerfile .
docker run -d -p 8080:8080 --name testapp testapp
```

### Standalone
```bash
cd dist/production/testapp
./run.sh          # Linux/macOS
run.bat           # Windows
```

### VPS (Linux)
```bash
# Copy files to server
scp -r dist/production/testapp user@server:/opt/testapp

# Install systemd service
sudo cp deploy/testapp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable testapp
sudo systemctl start testapp

# Check status
sudo systemctl status testapp
```

### Kubernetes
```bash
kubectl apply -f deploy/k8s-deployment.yaml
kubectl apply -f deploy/k8s-service.yaml
kubectl apply -f deploy/k8s-hpa.yaml
```

### Cloud Deploy
```bash
# AWS
bash deploy/deploy-aws.sh

# Google Cloud
bash deploy/deploy-gcp.sh

# Azure
bash deploy/deploy-azure.sh
```
